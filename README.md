# IT CREW DIGITAL — MVP платформы рекламных задач

Учебный мини-проект для лабораторной работы № 1 по теме «Метод и методология». Проект моделирует рекламную платформу, где заказчик формулирует задачу, публикует бриф, получает предложения и выбирает исполнителя.

## Связь с реальным MVP

Результат можно посмотреть на [опубликованном сайте IT CREW DIGITAL](https://it-crew-digital.okrupashiani.chatgpt.site/). Этот репозиторий содержит учебный кликабельный прототип той же логики, подготовленный для отчёта: форма брифа, карточки открытых задач, этапы сделки и локальное сохранение.

## Методология

Использована итерационная методология разработки: требования уточняются короткими циклами, после каждого цикла остаётся работоспособная версия прототипа.

## Методы

- анализ требований;
- декомпозиция задачи;
- use-case моделирование;
- прототипирование;
- человеко-ориентированное проектирование;
- функциональное тестирование;
- эвристическая оценка интерфейса.

## Запуск

```bash
cd lab1-it-crew-digital
python3 -m http.server 8081
```

Открыть: http://localhost:8081

Проверка:

```bash
npm test
```
